# Оставшиеся согласования после D51

2026-10-21. Срез текущего live-only ТЗ для Ethereum/BSC/Polygon до NATS. Принятые D16–D51 решения повторно не открываются. Незавершённые задачи реализации E01–E07 не являются автоматически новыми вопросами пользователю.

## Что ещё согласовать до финализации

1. **Запуск и остановка — DEP-03.3b.** Точные признаки завершения синхронизации каждого клиента, условия startup/readiness/liveness, поведение при зависании, порядок штатного завершения и время ожидания перед принудительной остановкой. Независимость сетей, H+1 и накопление WAL при недоступности NATS уже приняты.
2. **Размер транспортного сообщения — E00-11 пункт 3.** Единый параметр YAML и default максимального frame/части с учётом Protobuf envelope, gRPC и NATS; согласовать применение лимита и его изменения к сохранённым pending frames. Само разбиение крупных записей и неизменность bytes при retry уже приняты.
3. **Резервная копия документов — E00-05.** Оставляем только локальный Git или подключаем remote/иной backup; при выборе remote — адрес и отдельное разрешение на публикацию. Локальные коммиты уже обязательны, публичная open-source поставка отложена.
4. **Завершение ТЗ — E00-11 пункт 4 / E00-05.** Отделить принятие финального документа от разрешения начать реализацию в формальных критериях плана. Сейчас разрешены только документы; завершение интервью не разрешает код. Начало реализации — отдельное последующее указание пользователя, не обязательное решение сейчас.

## Что ещё дописать/проверить технически

- **DEP-03.2b.2b.3b:** точные native flags/config keys, filenames/mounts и механика init Compose/Kubernetes, в том числе обновление пользовательских настроек без перезаписи state/ключей. Принцип принят D51; уточнения, которые меняют поведение, сначала согласовывать.
- **Pins/источники:** закрепить способ получения образов/сборок, source/toolchain pins и проверить изменения native hooks Geth/Bor. Не выдавать source audit за совместную сборку/runtime. Digests собственных сборок и runtime-проверки появляются на стадии реализации, не изобретаются в ТЗ. Если потребуется смена принятых кандидатов D47 — отдельное согласование.
- **DEP-04 / E00-11:** итоговая сверка всех документов, YAML, независимых WAL и границы NATS; явные критерии будущих функциональных проверок. Финальное подтверждение пакета после устранения противоречий.

Это остаток по текущему документированному scope, а не гарантия отсутствия новых находок при проверке flags/версий. Технические детали можно исследовать и предложить без повторного обсуждения уже принятых принципов.

## Не возвращать в текущие согласования

История/догрузка пропусков, Base/Arbitrum, ClickHouse/downstream, production HA/мульти-ДЦ, production-методика тестирования, требования производительности, лицензия и публичная open-source поставка остаются отложенными либо вне scope. Optional изменения балансов вне транзакций не становятся обязательным gate. Выбранные RocksDB, независимые WAL/Gateway, порты, клиентские кандидаты, layout и init-модель повторного подтверждения не требуют.
