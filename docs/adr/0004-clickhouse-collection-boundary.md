# Граница проекта — сбор данных и запись в ClickHouse

Пользователь определил конечный результат как систему сбора данных из блокчейнов и загрузки в ClickHouse; внешние потребители получают сведения запросами к этой БД. Поэтому в поставку входят production-загрузчик, схема хранения, доступные через SQL сведения о каноничности/полноте и проверки корректности записей; успешная публикация в NATS сама по себе не завершает обработку для целей приёмки.

Существующие NATS, Gateway и WAL остаются внутренними частями проектного контура доставки, а не интерфейсом внешнего чтения. Прикладные API, бизнес-аналитика и пользовательские интерфейсы не разрабатываются; конкретные схемы, драйвер, batching и способ загрузки начальных балансов ещё выбираются.
