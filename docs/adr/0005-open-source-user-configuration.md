# Open-source сборщик с пользовательской конфигурацией

Пользователь определил проект как open-source систему, в которой конечный пользователь выбирает поддерживаемые блокчейны и параметры загрузки через .yml файлы. Поэтому конфигурационные профили, их проверка, воспроизводимая сборка и инструкции самостоятельного развёртывания входят в продукт, а окружение конкретного разработчика не задаёт фиксированный набор сетей.

Конкретная лицензия, публичный repository и поля hot reload ещё выбираются. После D14 связь ранее принятой автоматической догрузки при изменении стартового блока с отдельной командой N–M уточняется в JOB-01. По D15 новая сеть запускается отдельным процессом, изменения её конфигурации не перезапускают остальные сети. YAML выбирает готовые адаптеры и не заменяет реализацию нового runtime. Решение не означает, что код уже опубликован или LICENSE уже выбран.
