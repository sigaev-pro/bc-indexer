# Пять сетей в первом контуре

Пользователь выбрал Ethereum, BSC, Base, Arbitrum и Polygon для начала разработки, чтобы сразу охватить разные разновидности сетей. Поэтому общий контракт проверяется на представителях всех пяти сетей до утверждения, а первая поставка не ограничивается Ethereum с последующим переносом остальных четырёх.

Это увеличивает объём первоначальной проверки интеграций, но снижает риск спроектировать общий протокол только под Ethereum. Точные варианты сетей, клиенты, история, сроки и степень параллельности работы ещё не выбраны; Polygon не приравнивается автоматически к конкретному runtime, а Base — к Reth.
