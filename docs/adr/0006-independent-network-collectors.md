# Независимые процессы сетей и отдельные задания истории

2026-11-04: независимость контуров подтверждена D40/D48; история N–M отложена D38. Конфигурация live/Gateway применяется перезапуском, вариант reload уже выбран. [Журнал решений](../DECISIONS.md) имеет приоритет; ниже сохранён исторический контекст решения 2026-10-14/15, а не обязательство реализовать history в текущем этапе.

Пользователь подтвердил, что каждая сеть работает отдельным процессом/узлом/pod, а изменение параметров или добавление одной сети не затрагивает остальные. Поэтому сбор не строится как единый процесс с глобально перезагружаемым списком сетей; обычный live непрерывен, а пользователь может отдельно запросить исторический диапазон N–M без его остановки.

2026-10-15 / D19: приняты собственные native node/adapter, Gateway, WAL и журнал публикации каждой сети; общий NATS с раздельными streams/subjects и лимитами. Сети не зависят от конфигурации, прогресса или работоспособности соседних сборщиков. Изоляция ресурсов проверяется; общий кластер остаётся общей инфраструктурой. D20 откладывает управление историей/YAML в отдельное обсуждение, вариант reload не выбран.
