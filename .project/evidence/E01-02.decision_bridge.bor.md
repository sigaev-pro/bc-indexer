# E01-02.decision_bridge: Bor block (partial, #17)

This block joins the decision core of block 0 (PR #157) to the Bor product
import path: the native marker patch at the decision write of
`processBlockForImport`'s import (`insertChain`), the child-root barrier
over the hash trie database, the import-path calls (`Intend`, `Resolve`,
`RejectIntent`, `Cleanup`), the switch of the admission to
`OpenWithCleanup` with a `source_inputs.Purge` adapter, and the recovery
driver that settles saved intents and completes the native import of every
EXEC_READY observation in RECOVERY_ONLY before `decision.Bridge.GoLive`. The
design is in [adapters/bor/decision/native/README.md](../../adapters/bor/decision/native/README.md);
the plan rows are in PROJECT_STATUS ("E01-02.decision_bridge", plan for the
per-client blocks, and "E01-02.decision_bridge — Bor block").

Scope of this evidence: private local POLY only (fixture chain 15001, one
validator, stub Heimdall). Every public profile cell (Polygon Mainnet, Amoy)
stays NOT_RUN (D96, D98, D99). #17 stays open until the Geth and BSC blocks
are accepted too.

the independent consumed manifest and native result (on the snapshot taken

before E05-01.registry), no pin, capsule, log or admission record left for a
closed observation, one decision per block in the store, and the bridge's
obligations equal to its NATIVE_DECIDED `BATCH` decisions.
