## Implemented component probe

The native test calls `Transaction.UnmarshalBinary`, `MakeSigner`, native
sender recovery, and `Parlia.IsSystemTransaction`. It checks all five
native wire variants, before-activation signer refusal, all unknown typed
IDs 5 through 127, and positive/negative system classification. Native
classification preserves the original transaction hash and type.

This is deliberately not block-import proof. Blob and SetCode envelopes
exercise decoding and signature recovery, not execution validity. The
bounded driver refuses to convert this result into import, system-state,
or public-profile credit. Design and commands:
[BSC native type-path fixtures](../../test/type_paths/bsc/README.md).

## Modern validator initialization prerequisite

The separate [initialization probe](../../test/type_paths/bsc/modern_init/README.md)
ran on clean `0aefa19bed66cf26677be54876eade9c0eb9a238`. This is a prerequisite
for the [modern import design](../../test/type_paths/bsc/MODERN_IMPORT_DESIGN.md),
not full current-fork import proof. It directly invokes the native Parlia
system-transaction executor with explicitly allocated modern contract code.
No block header is validated or imported and no extractor observation occurs.

The probe allocates the latest native code for all 17 system contracts through
Pasteur, verifies the unchanged native config's fork ordering, and executes
validator `init()` followed by `deposit()` in the actual current-fork context.
The private signer is absent from the embedded mainnet validator set: mapping
index0, total incoming0, turn length0 and anti-MEV ratio0 are explicit checked
preconditions. This is the deprecated-validator deposit branch. It does not
establish active-validator income or complete system initialization.

The independent Solidity-source oracle checks both selected before/after
states. Initialization sets slot0 and the embedded validator-array length;
deposit10000 wei yields reward625, burn1000, validator8375, coinbase0 and
coinbase nonce2 after the two native system transactions. It also checks
reward/burn settings and the unmapped-validator branch state. All allocated
bytecode SHA256 values must equal the pinned
[provenance manifest](../../test/type_paths/bsc/modern_init/provenance.json).
The oracle uses the exact Lorentz contract revision, with retained fetched
source bytes matching upstream Git blob identities; no result is inferred
from roots alone or from a second execution as expected data.
