What this shows: the seam keeps captured bytes owned while native memory
changes (AC-CAP-05-01 behavior), holds memory within the budget, and stops
native progress at a VM safe point and at a caller-side import boundary, then

not show: Parlia, Bor consensus, system transactions, StateSync or any public
profile; all families use one Ethereum-style genesis with the ethash faker. The
VM safe point is a test-only interpreter line, and the import-boundary wait is
between `InsertChain` calls, not inside the client's block loop.
