## Limits

- A SIGKILL is a process crash. The probe writes the admission records, the
  capsule and the log through a power-loss store model that keeps writes in
  process memory until `SyncKeyValue`, so a kill before a sync loses every
  unsynced extractor write, one subset that a power loss may keep. Native
  chain data and the pin ledger are written to the native store directly and
  keep process-crash semantics; the block 0 unit tests cover every subset of
  unsynced extractor writes.
- Ethash faker, private local chain, London rules, serial processor. The
  parallel processor is turned off for admitted blocks because it reads
  neither the saved BLOCKHASH answers nor the safe point.
- The execution digest is `ExecResultDigest` (block hash, gas used and
  receipts) until the capture side computes the record corpus digest.
- The normalization profile is the stand-in ID `test-only-probe-v1`
  (D99 item 4, E04-01.block_record).
- The patched `geth` command is built with a plain `go build -trimpath` of
  `./cmd/geth` with the accepted compiler and module cache, not with the
  release build script of E01-01.builds.
- Startup repair rewinds keep native behavior, and `geth removedb` and manual
  database tools are not guarded (see the README limits).
- No AC verdict for public profiles, no RunManifest, no public-profile credit.
