# E01-03.smoke_corpus: minimal independent native test corpus (#19)

The corpus has transfer, nested-revert, fee, system-action and empty-block
cases for ETH (Geth), BSC (Parlia) and POLY (Bor) on the private local
fixtures, each with independent expected results. It is small. It is not
full production semantic coverage: TC02, the BOOT-08 catalog and the native
type matrix of E01-05.type_paths stay with their owners.

Every public cell stays NOT_RUN (D96). Under D101 only short measured runs
are allowed; no long, load or product run.

## Block 0: corpus-core

Scope: the oracle and reference executor for all three families, the case
list with provenance, the observation format, the comparator, portable
controls and mutants. No native client runs in this block, and it gives no
case verdict. Design and commands: [test/native_corpus/README.md](../../test/native_corpus/README.md).
The written oracle: [test/native_corpus/ORACLE.md](../../test/native_corpus/ORACLE.md).

### What block 0 fixes

| Item | Where |
|---|---|
| Cases per family, with applicability | `expected/<family>.json` `cases`; ETH system-action is NOT_APPLICABLE with its reason |
| Provenance | `expected/<family>.json` `fixture` (genesis path and native source commit), `genesis_additions` (the corpus accounts and their hand-assembled code) |
| Independent expected results | `corpus_oracle.py` and `corpus_evm.py`; per transaction the fields, receipt, logs, effective gas price, fee split, call frames and the state of the listed accounts before and after; per block the body count, base fee, gas, system transactions, state sync and block-end state |
| Observation format | README "Observation format" |
| Comparator | `corpus_compare.py`: per-case PASS, FAIL or NOT_APPLICABLE, with every difference and its place |

Independence: the expected files come from `corpus_oracle.py`, which
reads no native output. Its reference executor is checked against the
published EIP-2200 and EIP-3529 gas tables. The case totals are checked
against hand arithmetic written in ORACLE.md: nested 142,655 gas (London)
and 130,255 (Istanbul), direct revert 43,883 and 41,783, the fee splits, and
the BSC and Bor system actions. `corpus_oracle.py check` proves that the
committed expected files are its output.

## Limitations of block 0

- The reference executor covers only the opcodes of the corpus contracts and
  refuses every other opcode.
- System-contract internals (BSC `init()` effects, the Bor span commit and
  the StateReceiver storage other than `lastStateId()`) are not modeled; the
  oracle lists them as not asserted.
- The Bor StateSync expectation rests on the genesis StateReceiver behavior
  read from its bytecode (selectors, the 5,000,000 gas call of
  `onStateReceive`, no event); the POLY block's native run is the first
  check of it.
